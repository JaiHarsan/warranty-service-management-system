# Project Objectives

1. **Centralize Household Products**: Provide a single dashboard to track all registered products and their metadata.
2. **Track Warranty Periods**: Dynamically calculate warranty expiration dates and visualize remaining validity.
3. **Notify Users**: Alert users automatically before critical warranty milestones expire (e.g., 30 days remaining).
4. **Health Checks**: Provide product-specific symptom questionnaires for active monitoring.
5. **Rule-Based Intelligence**: Categorize risk levels based on deterministic logic to identify potential issues without claiming guaranteed medical/technical diagnostics.
6. **Service Centre Discovery**: Help users find relevant, nearby authorized service centres based on brand and coordinates.
7. **Prototype Service Requests**: Allow users to generate local mock appointment identifiers for streamlined service flows.
8. **Data Isolation & Security**: Protect user payloads using Bearer Token authentication and secure PBKDF2 hashing.
